## 作るもの

### 1. 会場を契約の住所で見分ける（13.1 の追加の決定 6）
- 入れる先の住所と、会場の登録にある公式の住所を比べます。登録は venues/*.yaml と chains/*.yaml です。
- 入れる先の住所は、次のどれかです。
  - プールの住所
  - Uniswap v4 なら、「プールをまとめて預かる契約」の住所とプールの番号
  - 金庫の住所
- 住所が合えば「見分け済み」になり、その会場の情報（監査・事件など）を使います。
- 合わなければ「仮・会場の見分けが不確か」の印のままです。おすすめにも入れません。
- 登録するのは、公式の資料かエクスプローラーで確かめた住所だけです。出典と確認日を書きます（絶対ルール3）。
- 登録する順番:
  1. Uniswap（N3 で済み）
  2. up. と Alandale（すでに登録済み）
  3. Merkl の一覧で、Robinhood と Base の上位の会場から1つずつ
- 確かめられない会場は登録しません。その場合は、どこまで調べたかを PROGRESS.md に書きます。

### 2. 危なさの点数（今の「仮の3段階の安全度」を置き換える）
- 材料:
  - 会場の年齢（90日が目安）
  - 監査の数
  - 事件の記録
  - 預かり額の大きさと、1時間・1日での減り方
  - 運営の鍵（1人の鍵か、複数人の承認か、時間を置く仕組みがあるか）。チェーンで読める会場だけです。
  - ボーナスのコインの売り場の深さ
  - バグ報奨金
- 読めない材料は「不明」として、危ない側に数えます。
- 点数は4つの区分に分けます: 低い・中くらい・高い・とても高い。
- 区分ごとに「この入れる先に、いくらまで置いてよいか」（推奨金額）を、理由と一緒に出します。
  - 例:「上限 $500。会場が動いて60日、監査1件」
  - 区分ごとの割合は SPEC の案を使います。低い 25%、中くらい 15%、高いは1つ 5〜10%・合計 20% まで、とても高いは練習だけ。
  - 小資金（$2,000 未満）は、警告をつけて全額でもよいことにします。
  - 元になる上限は config.yaml の limits です。変えるのはオーナーだけです（絶対ルール5）。

### 3. 損の線
- 3つの段階（注意・新しく入らない・すべて止める）を、3つの期間（1日・1週間・始めてから）ごとに決めます。
- % と金額の両方を出します。
- 数える損:
  - プールの値動き
  - まだ売っていないボーナス（今売ったらいくらか）
  - 保険の損益
  - 移る費用とガス代
- 「1日 −5% で止める」は決定済みです（13.1 の12）。それ以外の数字は、下の判断2で決めます。

### 4. 早く出る4段階の表と、止め方
- 4つの段階の合図を、今あるデータで判断します（SPEC 13.2 の表。数字はすべて仮）。
  - **段階1**: 預かり額が1時間で −30%、運営が仕組みを変えた（チェーンで読める会場だけ）、ドルのコインが2%以上ずれた。
  - **段階2**: 残る利回りが狙い利回りを3回続けて下回った、またはボーナスのコインが24時間で −15%。
  - **段階3**: 配る期間の終わりが近く、移る費用を取り返せない。
  - **段階4**: （利回りの差 × 残りの日数）が、移る費用の2倍より大きい。
- 止め方は段階ごとに3つから選べます。
  - 自動で出る
  - 知らせて、自分で決める
  - 知らせて、返事がなければ一定時間後に出る
- 練習の初期値は、下の判断1で決めます。知らせは画面だけです（Telegram は本番から）。
- まずは今の練習（自分で読む会場のプール）に当てて動かします。
- Merkl の入れる先の練習は N6 です。N4 では、合図を一覧と詳しい画面に出すところまでにします。

### 5. 保険（Lighter）
- 保険に預けるお金を「置いている場所（Lighter）」として上限に数えます。守るの画面に Lighter の行を出します。
- 強制決済に近づいたときの知らせ:
  - 値段が上がって証拠金の余裕が減ったら知らせます。
  - 知らせる目安は仮で、余裕がはじめの半分を切ったときです。
  - 対応は「お金を足す」か「出る」から選べるようにします。
  - 練習では「値段が ○% 上がったら」を押して、知らせと対応を試せるボタンを作ります。
- 幅から出たときの保険の扱いは、下の判断3で決めます。

### 6. 画面とテスト
- **守る**: 次のものを並べます。
  - 会場ごと・チェーンごと・Lighter の、置いている額と上限
  - 損の線の今の位置
  - 段階の合図の一覧
- **探す・詳しい画面**: 危なさの点数、推奨金額とその理由、見分け済みかどうかを出します。
- テストを足し、PR を作り、1行の更新でパソコンに入れます。

## 判断が必要な点

### 1. 練習での止め方の初期値
- **A（おすすめ）**: 練習では、4つの段階とも自動で出ます。どの決まりで出たかを記録します。
- **B**: 段階1だけ自動で出ます。段階2〜4は知らせるだけで、出るかどうかは自分で決めます。
- **おすすめの理由**: 練習は返事をする人がいない時間も長いです。決まりが正しく動いたかの答え合わせ（N6）に、記録をそろえられます。本番の初期値は別に決めます。

### 2. 損の線の仮の数字（N5 で決め直すまで）
- **A（おすすめ）**: 次の表の数字を仮に使います。「仮」の印をつけます。

  | 期間 | 注意 | 新しく入らない | すべて止める |
  |---|---|---|---|
  | 1日 | −3% | −4% | −5% |
  | 1週間 | −7% | −10% | −12% |
  | 始めてから | −10% | −15% | −20% |

- **B**: 「1日 −5% で止める」だけを使います。ほかの線は N5 まで出しません。
- **おすすめの理由**: 「止める」の前に「注意」が出るので、近づいていることに早く気づけます。数字はどれも、N5 の試しで決め直します。

### 3. 値段が幅から出たときの保険
- **A（おすすめ）**: 次のようにします。直す費用は計算に入れます。
  - 幅の上に出たら、プールの中身はドルのコインだけになるので、保険を閉じます。
  - 幅の下に出たら、プールの中身は値動きするコインだけになるので、保険を中身に合わせて大きくします。
- **B**: プールを置き直すまで、保険はそのままにします。
- **おすすめの理由**: 上に出たまま保険を残すと、値段が上がるほど保険の損だけが増えます。オーナーの提案（13.1）と同じ考えです。
