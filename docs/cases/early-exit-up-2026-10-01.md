## 何が起きたか（オーナーの報告）

- 練習の建玉2つ（id 3 WETH/USDG、id 4 USDG/NVDA。各 $1,000）が、離脱の決まり「報酬トークンが24時間で −20% 以下」で自動で閉じられた。

## アプリの決まり（今の版 = main 04b555b。コードで確認）
- 15分ごとの収集（UTC の 0・15・30・45 分）のすぐあとに見張りが動く（`execution/risk_job.run_risk`）。21:45 JST = 12:45 UTC の回。
- UP のドルの値段は、自分の記録（up. のプールの値段）から作る（`scoring/prices.usd_prices`。今の値段のところで一番深いプールを使う）。
  24時間の変化 = 今の値段 ÷ 24時間前かそれより前の最後の記録 − 1（`views.series_change`）。
- −20% 以下なら「離脱」。建玉の番号の順（id 3 → id 4）に、同じ回の中で続けて閉じる。ガス代が上限を超えていれば見送る決まりがある。
- 閉じるときの値段は、その建玉のプールの最新の記録（12:45 の回）。

## 新しい版の試験に使うこと
- 「報酬トークンが急に売られた」場面。−20% の線を越えたのは売りから5分以内の最初の回だった。15分ごとの見張りだと、売りの始まり（21:40）から判断（21:45）まで約5分。
- 比べる: 1分ごと・5分ごとの見張りなら、いくらで出られたか。毎日売る形なら、持っていた UP の分の損はどれだけ減ったか。
- オーナーのパソコンの記録（判定の時刻・閉じた値段・順番）を受け取ったら、この表に足す。
