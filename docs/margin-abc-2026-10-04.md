# 保険の預け金の決め方 A/B/C（2026-10-04 JST。オーナーの質問1）

数字はすべて **Lighter の公開の記録（作業場所で読んだ値）** です。2026-10-04 09時台 JST に読んだ、保険に使う29市場の1時間の足と資金調達率の120日分（MRNA は45日分）を使いました。
あなたのパソコンの記録ではありません。

## 1. 「幅の上に出たら保険を閉じる」なら、上の端までで足りるのでは？

- **1回の置き方だけを見れば、そのとおりです。** 売り（保険）が損をするのは、入った値段から幅の上の端まで（±2% なら約 2%）と、置き直すか保険を閉じるまでの短い飛びの分だけです。
- **ただ、アプリは幅の外に15分いたら置き直します。** 置き直すと、保険は新しい値段で建て直します。それまでの売りの損は Lighter の口座に残ります。
  プールの側の得はチェーンのプールに残り、Lighter には移しません。
- そのため、値段が上がり続けると、置き直すたびに Lighter の損が積み上がります。±2% の幅で 58% 上がれば、置き直しは20回をこえます。
- 「保険を閉じる」決まり（幅の上に10%の余裕をこえて30分）が動くのは、ガス代が高くて置き直しを見送ったときだけです。ふだんはその前に置き直します。
- そこで、いる日数（14日）のあいだの「いちばんの上げ」で預け金を決めていました。
- 置き直しをまねた計算でも、14日のあいだに積み上がった売りの損は、上げの幅に近くなりました。
  例（いちばん悪い入り方）: SNDK は ±2% で 41.6%、±15% で 43.6%（上げは 58.4%）。NVDA は 17.4% と 18.3%（上げは 19.7%）。ETH は 32.7% と 34.4%（上げは 37.8%）。
  6時間ごとの入り方のすべてで調べました。
- 置き直すたびに保険の大きさがドルで同じに戻るので、損は上げの幅よりやや小さくなります。

## 2. 同じ例での A/B/C

- 例: $1,000 の練習で、予備は $20 です。値動きするコインは1つで、もう1つはドルのコインです。保険の額はプールの半分です。
- 預け金の式は今と同じで、`max(最初に要る割合, 耐える上げ u + (1+u) × 維持の割合)` です。Lighter の割合は NVDA と SNDK が 6.7%/3%、ETH が 5%/1.2% です。
- 年利は「プールに入れたお金が、費用を引いたあとで年 50% 稼ぐ」と仮に置いた例です。総額 $1,000 あたりで示します。保険の資金調達料は入れていません。

| 例 | A: 市場ごとの14日のいちばんの上げ（50%より下にしない） | B: どれも 50%（超えた市場に印） | C: 上の端 + 置き直すまでの飛び + 余裕 5% |
|---|---|---|---|
| NVDA ±2% | 耐える 50% / 預け金 $210 / プール $770 / 年利 38.5% | 50% / $210 / $770 / 38.5% | 11.7% / $69 / $911 / 45.6% |
| NVDA ±15% | 50% / $210 / $770 / 38.5% | 50% / $210 / $770 / 38.5% | 24.7% / $122 / $858 / 42.9% |
| SNDK ±2% | 58.4% / $235 / $745 / 37.2% | 50% / $210 / $770 / 38.5% | 19.3% / $100 / $880 / 44.0% |
| SNDK ±15% | 58.4% / $235 / $745 / 37.2% | 50% / $210 / $770 / 38.5% | 32.3% / $150 / $830 / 41.5% |

C の「飛び」は、その市場の120日で1時間にいちばん上がった幅です（NVDA 4.7%、SNDK 12.3%、ETH 7.5%）。

## 3. 120日の記録に当てはめると

- 置き直しをまねた計算です。入る時刻は6時間ごとで、それぞれ14日いたとしました。
- **A**: 強制的に閉じられたことはありません（29市場すべて）。
- **B**: NBIS だけ、410回の入り方のうち4回で 50% をこえ、強制的に閉じられました。ほかの28市場はありません。
- **C**: Lighter にお金を足さないと、置き直しを重ねるうちに足りなくなります。置き直しのたびに足りない分を足すとして数えました。

  | 例 | 足しが要った入り方の割合 | いちばん悪い14日 |
  |---|---|---|
  | NVDA ±2% | 87% | 8回・$78 |
  | NVDA ±15% | 2% | 1回・$69 |
  | SNDK ±2% | 95% | 16回・$180 |
  | SNDK ±15% | 60% | 3回・$169 |
  | ETH ±2% | 97% | 8回・$138 |
  | ETH ±15% | 21% | 1回・$80 |

  足していれば、強制的に閉じられたことはありません。
- 本物のお金で足すには、プールから出して Lighter へ送ります。その道すじ（Robinhood Chain → Lighter）の費用と時間は、まだ確かめていません。

## 4. C のときの「保険を閉じるまでの時間」（今のアプリの決まり）

- **幅の外に出てから置き直すまで: 15〜30分。** 15分待ってから置き直します。見張りは15分ごとです（米国の市場が開く前後は5分ごと）。
- **ガス代が高くて置き直しを見送ったとき: 30〜45分。** 幅の10%の余裕より外に30分いたら、保険を閉じます。
- **株の市場が閉まっている時間:** Lighter の株の売り場は週末も値段が動きます。ただ、値動きは小さめです。
  例: NVDA の1時間の高値と安値の差は、平日が約 0.5%、週末が約 0.2% でした。
  市場が開くときの飛びは、上の「1時間でいちばんの上げ」に入っています。
- **パソコンかアプリが止まっているあいだ:** 何もしません（欠損として記録します）。そのあいだに上がった分は、どの決まりでも守れません。

## 5. 資金調達料の見込み（オーナーの質問5）

- 120日の記録では、29市場のうち28市場で、売り（保険）の側は平均して資金調達料を**受け取って**いました。MRNA はほぼ 0 でした。
  例: ETH は年 7.3%、NVDA は年 7.2%、SNDK は年 12.2%、MSTR は年 6.2% の受け取りでした。
- アプリは受け取りを収入に数えません（0 とみなします）。そのため、見込みはすでに安全側です。
- 14日いたときに、実際の支払いが見込み（7日の平均）より多かったのは、全体の約 1% でした。平均の差は年 0.06% でした。
- 7日と30日の悪い方を使っても、この120日では結果が同じでした（7日の平均が「払う」になった日が少ないため）。
- 1日ずつ比べると「合」が低いのは、資金調達率が日ごとに上下するためです（1日の比べ方）。14日の平均で見ると、見込みが低すぎたことはほとんどありません。
